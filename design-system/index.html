Customer primary

See a screen in any customer's colour

Each customer can set their own primary. Every primary role (button fill, link text, subtle surfaces, borders, focus ring) is derived from that one colour.

ASK How does production derive the roles? This site uses Bootstrap's own scale recipe (scss/_colors.scss) and role map (scss/_theme.scss). Production may do it differently. The preview is only exact once it copies the production code.

Status and accentfixed
  • At most one primary action per screen. Primary never means new, recommended or important.
  • Status colours report state only. Never actions, emphasis or decoration.
  • Colour is never the only signal. Carry meaning with two of colour, icon and text.
  • No hex values in component or page CSS. A colour that is not in the theme does not exist.
  • Red or orange primaries: danger and warning must carry an icon or text as well as hue.

    Guidelines vs Bootstrap 6real findings from bootstrap-v6-dev@bc4bcb4
    • Fixed here
      Default primary fails contrast.

      Bootstrap's primary fill is blue-500. White text on it is below 4.5:1. The colour page says to use blue-600, so filmmakers.css overrides it.

    • Fixed here
      Headings default to weight 500.

      Bootstrap 6 sets headings to --bs-font-weight-medium. The typography page bans 500, so filmmakers.css sets --bs-heading-font-weight: 600. Prose headings, .otp-slot and .fw-medium still use 500 directly.

    • ASK
      The focus ring fails 3:1.

      Bootstrap mixes the primary 50% into the page background for --bs-primary-focus-ring. With the default primary that gives about 2.2:1 on white, below the 3:1 the colour page asks for focus indicators. Check the live value in the Colour section.

    • ASK
      Client zone orange fails 3:1 as an icon.

      Bootstrap orange-500 on white is about 2.9:1. The client zone icon is a meaningful graphic, so it needs 3:1. A darker step such as orange-600 would pass, but changing the accent is a decision.

    • ASK
      "Accent" means two things.

      Bootstrap 6 has a theme colour called accent (indigo, .theme-accent). Our colour page uses Accent for area colours such as the orange client zone. Tokens and Figma variables need one meaning per name.

    • Guideline fix
      --bs-secondary-color does not exist in Bootstrap 6.

      The typography page tells people to de-emphasise text with it. That is a Bootstrap 5 token. Bootstrap 6 uses --bs-fg-2 / --bs-fg-3 (utilities .fg-2, .fg-3). The page needs updating.

    • Watching
      Bootstrap 6 is alpha.

      Token names can still change. The vendored CSS and the bootstrap group in tokens.json should be regenerated from the source on each upgrade, never edited by hand.
